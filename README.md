#  Age Calculator

A responsive and user-friendly Age Calculator built with **React.js** and **Tailwind CSS**.

Users can enter their date of birth and calculate their exact age in **years, months, and days**. The application also shows the number of days remaining until the user's next birthday and provides an option to share the result.

🔗 [Live Demo](https://agecalculator-three-coral.vercel.app/)

##  GitHub Repository

🔗 [GitHub Repository](https://github.com/MahmudunNabi-N/age-calculator)

---

##  Features

-  Calculate age from date of birth
-  Day, month and year input
-  Display age in:
  - Years
  - Months
  - Days
-  Calculate days remaining until the next birthday
-  Share age result
-  Validation for empty inputs
-  Prevent future birth dates
-  Fully responsive design
-  Clean and modern UI
-  Fast and lightweight React application
